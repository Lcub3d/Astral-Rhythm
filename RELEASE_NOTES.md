**Work in rhythm.**

## 中文

英文名称正式定为 **Astral Rhythm**，中文仍为 **七曜工作法**。上方标题为“曜星”；保留 V3 山岚双卡、透明任务栏按钮、五行文字配色和中英文切换。工作建议与用户设置保持兼容。

完整解压 Windows x64 包，先退出旧版，然后运行 `AstralRhythm.exe`。右键切换语言。旧版自定义“表格”文件夹可复制到新版。成品不需要额外运行环境。

## English

The English name is now **Astral Rhythm**. This release updates the executable, launchers, Windows version resources and documentation without changing the V3 interface or source guidance. Settings remain in `%APPDATA%\Astral` for compatibility.

Extract the entire portable ZIP, close the previous version and run `AstralRhythm.exe`. Select Language in the context menu. Preserve your customized workbooks by copying the old `表格` folder into this package.

Test records are included in `validation/` when available. Automated tests and compilation do not establish real Windows desktop visual validation. The executable is not digitally signed.
