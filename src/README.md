# Astral Rhythm · 原生 Windows 源码

See [English instructions](../README.md) or [中文说明](../README.zh-CN.md).

The module uses Go 1.23+ and the standard library. `locale.go` is shared by cross-platform tests; `locale_windows.go` detects the Windows UI language, switches fonts and resizes existing windows.

`layout.go` drives both languages with the same compact geometry. `locales/en.json` contains source-exact translations. `core.go` preserves the original workbook reader and local-time mapping. `ui_windows.go` and `surface_windows.go` draw per-pixel alpha windows without a taskbar plate.

Run `go test -v ./...` and compile with `build.cmd` on Windows. The `.syso` file is generated by `../tools/build_resources.py` and contains the version, icon and PerMonitorV2 manifest. It is a compiled resource object, not a font or executable dependency.

The legacy `QiyaoShichen` Win32 class/mutex and migration identifiers are intentionally retained to detect previous versions and read existing preferences. They are not the displayed software name.

Native Windows `go vet` reports an existing external-memory conversion at `GlobalLock` in the clipboard path. Linux logic vet passes; the Windows compile still succeeds. Do not suppress unrelated checks or mistake cross-compilation for GUI testing.

Read `../.agents/skills/astral-ui/SKILL.md` before changing visual design.
