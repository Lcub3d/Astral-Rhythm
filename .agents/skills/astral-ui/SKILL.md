# V3 界面规则

## 基准
以用户最后确认的小幅参考图为准：青灰暗色双卡、精细线稿图标、上暖下冷的克制山岚装饰、适中密度。
不得恢复 V2 的大字号时辰主视觉、宋体大标题、总标题栏和底部按钮栏。
任务栏第一行曜星，第二行时辰。悬浮卡顺序相同。

## 文字与数据
只从原有 Excel 读取工作安排和传统解释。不得把效果图里临时编写的建议写入原表或内置数据。
上卡：曜星、五行配色标记、星期与定位、象征、适宜事项。星名／宿曜／西方象征只在本卡的更多信息中展开。
下卡：时辰、时段、地支、藏干、含义、适宜事项及原表存在的工作等级。
不要合并两组解释；不要补出原表缺失的优先级。

## 几何与文字
320 DIP 宽；外边距 10；内边距 14；区块间距 10；外圆角 14，内圆角 11。
Microsoft YaHei UI；正文 12、行高 20；区块标题 15；主身份 16、600 字重。
各行按实际 Windows 字体测宽后折行，不截断原表文字；超出屏幕高度时滚动。
不分发字体文件。

## 五行配色
木青绿，火朱红，土黄，金银白，水蓝黑；深色任务栏的水使用灰蓝确保可读。
日曜按火、月曜按水是界面约定，不改写原表的阴阳传统说明。
时辰按地支本五行取色，不按某一个藏干取色。未时必须是土色，不能继续沿用旧效果图的绿色文字。
颜色集中在 assets/design.json，禁止在界面中散落不一致的重复映射。

## 背景与透明
任务栏不画任何底板、边框、阴影或悬停胶囊。只画线稿图标和彩色文字。
图标和字号颜色适应系统任务栏深浅；悬浮卡的主题可以单独选择。
上卡使用 day-{weekday} 底板，下卡使用 hour-{index} 底板，不互相替换；背景图保持宽高比，长内容向下延展纯色阅读区。
背景装饰集中右侧和上侧，末端必须精确渐变到所属表面色，不得出现截断山体或矩形拼接缝。

## 交互
常用操作移到右键菜单；禁止免责声明、使用说明、页脚说明和常驻底栏。
标题箭头在鼠标进入卡片后显示，两组分别展开，分别保存状态。
不要把系统托盘图标或 Explorer 内嵌任务栏接口说成已经实现；当前是主任务栏旁的原生贴附小窗。

## 验证
测试原表一致性、7 个曜星和 12 个地支元素映射、84 种组合及多个 DPI、字体可用宽度、长内容滚动、预乘 Alpha、背景分区与切换。
编译正式 Windows x64 EXE，更新 3.x 资源和 SHA256。
分别注明自动测试、内部布局渲染和真实 Windows GUI 测试，不能用生成图片代替可执行程序或实机证据。
